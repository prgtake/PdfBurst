PdfBurst (v1.0.0) - PDF画像切り抜きツール
=====================================================

PDFファイルから『連続して』特定の範囲を画像(JPG)として切り抜き、保存するためのシンプルなツールです。
高画質を維持したまま、論文や資料の図表を素早く『連続して』抽出することに特化しています。

-----------------------------------------------------
■ 使い方
-----------------------------------------------------
1. 「PdfBurst.exe」を実行します。
2. 上部の「PDFを開く」ボタンから、切り抜きたいPDFファイルを選択します。
3. ページ送りボタン（$25C0 前 / 次 $25B6）で目的のページに移動します。
4. 画像上の切り抜きたい範囲を、マウスの左クリックでドラッグして囲みます。
5. 範囲を決めると、保存の確認ダイアログが表示されます。
   ※「連続自動保存」にチェックを入れると、ダイアログなしで次々と保存できます。

   ★ 初回実行時に Windows Defender の警告が出た場合は、
   　「詳細情報」→「実行」をクリックしてください。

-----------------------------------------------------
■ 機能のポイント
-----------------------------------------------------
・【高画質保存】表示倍率に関わらず、常に内部で高解像度レンダリングを行って保存します。
・【表示倍率変更】画面が見えにくい場合は、表示倍率を 50%～200% で調整可能です。
・【連続自動保存】チェックをオンにすると、マウスで囲むだけで実行ファイルと同じ場所に
  「crop_p(ページ)_(日時).jpg」という名前で自動的に保存されます。

-----------------------------------------------------
■ 注意事項
-----------------------------------------------------
・このソフトはPDF内の「画像データ」を直接抽出するのではなく、
  「指定した範囲を画像として書き出す」仕組みです。
・非常に大きなPDFや、複雑な描画を含むPDFの場合、表示に時間がかかることがあります。
・出力先は、標準では本ソフトの実行ファイル（EXE）と同じ場所になります。
